# Codex 独立审查卡

按严重程度检查，先给证据和可复现步骤：

1. AI 审核、工艺路线和报价是否真正独立；任一功能是否偷偷依赖另一功能的历史、定稿或确认。
2. 三个功能是否都能从 PDF 上传走到独立 PDF 产物。
3. 工艺条件和成本参数是否自动补齐、显示来源并标记假设；是否冒充企业数据。
4. 报价金额是否只来自可测试公式，而不是模型直接给价。
5. 产品 UI 是否只呈现三个独立功能、统一 API 设置、结果、历史和 PDF 下载。
6. PDF、密钥、私有路径、模型原始错误是否可能进入响应、日志、导出或 Git。
7. 模型输出契约、证据关联和坐标校验是否 fail-closed；DeepSeek 是否只获得最小化文本。
8. 历史是否来自后端，并准确区分审核、工艺和报价记录。
9. 报告是否明确区分“AI 参考结果”与正式工程批准、投产工艺、商务报价。

修复后重跑同一组后端、前端和浏览器验证。不允许删除关键断言制造绿灯。
